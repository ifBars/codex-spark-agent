# Real-world Spark extension

This development slice records eight fresh Spark harness runs at medium reasoning across coding, repair, and quantitative scenarios. Every task passed its scenario validator and there were zero request failures.

It is a Spark-only extension, not a runner comparison: the native Codex CLI was blocked by preflight during this pass, so no Codex rows are fabricated or carried forward. Total tokens are summed from the recorded Spark response usage, and duration is wall-clock task time. The web explorer shows successful rows only and does not infer confidence intervals from one attempt per scenario.

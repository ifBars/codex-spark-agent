# Real-world paired quick slice

This development slice compares the Spark harness and native Codex CLI 0.146.0 at medium reasoning across four real-world scenarios. Each runner/scenario point contains one validation-passing attempt; no provider/API failures were present.

The slice is intentionally separate from the expanded reasoning matrix. It is a current smoke-scale comparison, not a replacement for the scenario-balanced nine-task snapshot. Weighted quality is the benchmark's behavioral quality score, total tokens are input plus output usage, and duration is wall-clock task time.

The source comparison was generated with successful-only filtering from the local benchmark report. The web explorer shows successful rows only and does not infer confidence intervals from a single attempt, so this view is presented without ranges.
